def compute_metrics(eval_preds):
    accuracy = evaluate.load("accuracy")  # Load metric
    logits, labels = eval_preds  # Unpack model predictions and true labels
    predictions = np.argmax(logits, axis=-1)  # Convert logits to class labels
    return accuracy.compute(references=labels, predictions=predictions)  # Returns a dictionary

accuracy.compute(...) returns the accuracy in dictionary form.

    f1 = evaluate.load("f1")

    return {
        "accuracy": accuracy.compute(references=labels, predictions=predictions)["accuracy"],

Checkpoint Frequency: The interval at which checkpoints are saved affects their numbering. If checkpoints are saved every 1000 steps, for example, then a checkpoint labeled "checkpoint_50000" means the model has trained for 50,000 steps.

Training Schedule: If learning rate schedules, early stopping, or other training adjustments are involved, later checkpoints may not necessarily imply better model performance.

Resumed Training: If training is interrupted and later resumed from a checkpoint, the numbering might still increase even if the training session was not continuous.
