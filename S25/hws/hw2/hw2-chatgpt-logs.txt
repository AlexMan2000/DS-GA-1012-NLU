def compute_metrics(eval_preds):
    accuracy = evaluate.load("accuracy")  # Load metric
    logits, labels = eval_preds  # Unpack model predictions and true labels
    predictions = np.argmax(logits, axis=-1)  # Convert logits to class labels
    return accuracy.compute(references=labels, predictions=predictions)  # Returns a dictionary
np.argmax(logits, axis=-1) converts raw logits into predicted class indices.
accuracy.compute(...) returns the accuracy in dictionary form.
🔹 Why Does It Return a Dictionary?
The Trainer class in Hugging Face expects evaluation metrics as a dictionary, allowing multiple metrics to be computed at once.

If you wanted to compute multiple metrics (e.g., accuracy & F1-score), you could modify compute_metrics like this:

编辑
def compute_metrics(eval_preds):
    accuracy = evaluate.load("accuracy")
    f1 = evaluate.load("f1")

    logits, labels = eval_preds
    predictions = np.argmax(logits, axis=-1)

    return {
        "accuracy": accuracy.compute(references=labels, predictions=predictions)["accuracy"],
        "f1": f1.compute(references=labels, predictions=predictions, average="weighted")["f1"]
    }
